# أكاديمية المحاسب الدولي v3

تطبيق تعليمي عربي للمحاسبين يحتوي مسارات IFRS / IAS و CMA، مع ملخصات وشروحات مطولة واختبارات متعددة الاختيار وشرح للإجابات.

## التحديثات

واجهة المستخدم تعرض زرًا بسيطًا باسم: التحقق من التحديثات الآن.
لا تظهر للمستخدم روابط JSON أو GitHub أو تفاصيل تقنية.
تمت إضافة أيقونة Android مخصصة للتطبيق بألوان كحلي وذهبي وتركواز.

للمطور فقط: رابط المحتوى الخارجي مضبوط داخل الثابت `defaultContentUrl` في `lib/main.dart`:

`https://raw.githubusercontent.com/aljwaal1/accountant-academy-content/main/academy_content.json`

يمكن تعديل ملف المحتوى في مستودع GitHub ثم يضغط المستخدم زر التحديث داخل التطبيق.

## مسار APK

بعد نجاح GitHub Actions سيظهر الملف هنا:

`apk/accountant-academy.apk`
